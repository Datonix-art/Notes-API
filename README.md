This is rest api in which you are able to sign up a user, login a user and make notes with different CRUD operations using express and its libraries.

npm install express bcrypt dotenv express

1. copy the github repository to ur own local machine
2. open that directory
3. create .env file for environmental variables 
4. create PORT=3000 SESSION_KEY="your_secret_key"
5. after, open bash terminal in the local directory and run "npm install"
6. run: "npm install express bcrypt dotenv express"
7. after it run "node server.js"
8. server is running, enjoy!
